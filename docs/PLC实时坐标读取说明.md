# PLC 实时坐标读取

启动项目的 `启动软件.bat`，在主界面下方工具栏点击“PLC 实时坐标”（位于“PLC 坐标”与“PLC 手动”之间）。
该窗口使用 Snap7 的传统 S7 PUT/GET 通道，只读 DB，不发送运动指令。打开即自动连接和读取，无需手动开始。
连接或读取失败显示原因、清空当前值，并每 2 秒自动重试。关闭窗口停止读取，重新打开会自动连接。
它独立于已有 Modbus 运动通道；这里的实际坐标不会自动替换数字孪生或运动控制中的坐标。

## 当前已准备的连接配置

- PLC IP：`10.11.207.100`（截图中的 2 线 CPU 1511C-1 PN）。
- TCP 端口：`102`；Rack：`0`；Slot：`1`。
- 读取间隔：默认 `200 ms`，指每轮读取后等待的时间；实际周期还包含通信耗时。
- 已按现场 DB18 截图配置：X/Y/Z/R 脉冲计数均为 DINT，字节偏移分别为 8/12/16/20。
- 这些是 HMI“当前编码值”的源变量，暂不换算毫米或角度；单位和倍率需现场确认。
- DB112 车厢数据为 34 个连续 DINT：396/400/404/408 为车厢长宽高及偏转角度；
  412/416/420 为前车板长宽高；424/428/432 为后车板长宽高。
- 顶点 1～8 每点占 12 字节（XYZ 各 4 字节），从 436 开始，第 8 点 XYZ 位于 520/524/528。
- 高板/低板按用户参考图对应前车板/后车板。这里的高度是 PLC 原字段，不重新计算板面高差。
- 有无垫木：DB112 偏移 548，INT；显示原始编码，含义待确认。
- 有无前挡板：DB112 偏移 550，INT；按 HMI 参考图 1=有、2=无，其余编码显示未确认。

## 操作步骤

1. 在连接 PLC 的电脑上确认网络可达。
2. 点击主界面“PLC 实时坐标”即可自动开始，顶部横向显示 XYZR，下部显示车厢信息、8 点 XYZ 和高低板尺寸。
3. 查明原 DB 中 X/Y/Z/R 的实际数据类型与字节偏移。在博途里确认该 DB 为非优化访问，CPU 允许远程 PUT/GET。
4. 如需修改连接参数，展开“连接与地址设置”，程序会先停止读取；等待当前请求结束后可编辑。
5. 点击“保存配置”，收起设置后自动重新连接。车厢块地址在 JSON 的 truck 项配置。
6. 成功后显示 PLC 原始值和最近读取时间；单位由 PLC 定义，窗口不做缩放。
7. 关闭窗口、修改配置或读取失败时当前值显示为“—”，避免旧数据被误认为当前坐标。故障排除后自动重连。

例如 `DB20.DBD100` 为 REAL：DB 编号填 `20`，字节偏移填 `100`，类型选 REAL。
如果是 LREAL，每个数占 8 字节；必须按博途实际偏移填写，不能沿用 REAL 的 4 字节步长。
DINT 为 4 字节有符号整数，不能按同为 4 字节的 REAL 解析。DB18 读取显示原始整数。
多个轴逐一读取，不保证它们来自同一个 PLC 扫描周期；这是监视用途，不是闭环控制反馈。

## 配置位置

窗口顶部有并列的“车厢实时数据”和“人工补偿”页签。点击主界面的“PLC 实时坐标”入口默认回到车厢实时数据。
人工补偿页显示 d_AxE1、d_AxE2、d_Ay、d_dx、d_dy 五项，保留对应的方向说明与参考范围。
“修改后值”和“输入值/设定值”都是只读显示，不提供修改确认、清零、初始化或开始计算操作。
DB102 的绝对字节偏移尚未提供：配置 compensation.enabled=false，applied/input 中偏移均为 null。
请根据 PLC DB102 实际结构确认两组变量的偏移后配置；仅凭 HMI 变量名不能推测地址或把两列当成同一变量。
设置 enabled=true 后，只读取非 null 的确认地址，类型为 DINT；未配置字段仍显示“待配置”。

配置保存在 `config/plc_coordinates.json`，也可在软件退出后手工修改。空地址使用 JSON 的 `null`。
打开窗口自动读取已配置地址，不会推测未知 DB/偏移。应用启动时未打开此窗口则不启动该读取通道。
不要在读取过程中手工修改文件；在窗口停止后修改并保存。

## 环境与现场条件

项目依赖已加入 `python-snap7==3.2.1`。迁移到另一台电脑后，运行 `安装环境.bat` 安装依赖。
当前项目的 `.venv` 已安装此依赖，此版本不需要单独下载 Snap7 DLL。

允许 PUT/GET 会开放传统 S7 内存读写访问，应限制在隔离的设备网络使用。
不要为测试直接修改生产 DB 的优化属性：切换优化属性并下载可能初始化 DB 当前值。
这里的窗口不修改 PLC 配置；相关博途配置需在现场确认后操作。

## 常见失败

- 无法连接：检查 IP、网卡路由、TCP 102、Rack/Slot。能 ping 通不等于 S7 端口可用。
- CPU 拒绝读取：检查 CPU 访问策略、PUT/GET、DB 是否非优化、DB 是否已下载。
- 地址越界：核对 DB 编号、字节偏移和块长度。
- 数值不符合预期：核对 REAL/LREAL、偏移、PLC 是否持续更新该变量，以及工程单位/比例。
- 停止暂未完成：程序等待当前网络请求返回，不强制结束线程，期间界面可继续操作。

验证范围：自动化测试覆盖类型解析、空配置、持久化、后台刷新、失败状态和停止清理。
真实 PLC 的地址、读取权限与数值仍需要现场联调确认。
