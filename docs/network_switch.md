# Wi-Fi 和 IP 一键切换

主窗口顶栏的按钮显示下一步操作：在雷达 Wi-Fi 上显示“切换到热点”，其他网络显示“切换到雷达工控机”。将鼠标放在按钮上可以查看当前 SSID、IPv4 和配置状态。启动时和每 15 秒读取一次状态；读取状态不会切换网络。

点击按钮后允许 Windows 的管理员权限申请。程序先连接目标 Wi-Fi，确认 SSID，再执行与桌面 BAT 相同的 IP 命令。取消授权不会执行切换。切换期间按钮不可重复点击，也不能启动下一步或自动运行；执行步骤、自动运行或 PLC 坐标待处理时不能切网。

默认参数位于 `config/network_switch.json`：

- 网卡：`WLAN`
- 热点：`OPPO Find X3`，IP 和 DNS 自动获取
- 雷达：`ASRS_ZDZC2`，IP `10.11.207.188`，掩码 `255.255.255.0`，网关 `10.11.200.1`

两个 Wi-Fi 必须先在 Windows 中手动连接并保存一次；程序复用已保存的配置，不保存密码。更换热点后修改 `hotspot_profile` 为新热点的已保存 Wi-Fi 配置名称（默认与 SSID 相同）。配置读取时无需重启，但请勿在切换过程中修改文件。

Wi-Fi 连接最多等待 30 秒，IP 就绪最多等待 45 秒，管理员授权时间另计。失败会显示原因，并重新读取实际网络状态；按钮保留失败操作的目标，便于重试。失败时可能已经连接新 Wi-Fi，但未完成 IP 配置，可以再次操作或使用原来的 BAT 恢复。程序不会自行回切，以免反复断网。

配置就绪只表示目标 Wi-Fi 和本机 IPv4 就绪，不代表已远程登录工控机或验证互联网可用性。雷达工控机仍按原有方式远程连接。

网络切换日志在 `logs/network_switch.log`，记录管理员进程退出码、结果读取和清理异常以及切换结果，不记录 Wi-Fi 密码。结果文件由普通程序预先创建，管理员进程只写入内容；临时文件清理失败不会覆盖切换成功或失败的实际结果。
